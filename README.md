# PKU Physics Lab Reports

本仓库收录李灿辉（Canhui Li）于北京大学物理学院本科阶段三门实验类课程的全部实验报告，
作为本人学习档案及面向后续选课同学的参考资料。

This repository contains all laboratory reports written by Canhui Li
for three undergraduate physics laboratory courses at Peking University,
shared as a personal academic archive and a learning reference for
follow-up students.
